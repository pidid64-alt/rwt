# РЗА-АТ — инженерная платформа расчёта уставок РЗА автотрансформаторов 110–500 кВ

Профессиональное ПО для расчёта, проверки, выбора и документального оформления уставок релейной
защиты и автоматики автотрансформаторов 110–500 кВ (службы РЗА энергосистем, проектные и
наладочные организации).

Исходный код приложения находится в каталоге **`rza_at/`**. Архив `workspace-*.zip` в корне
репозитория — исходный снимок проекта (первая поставка), рабочее дерево — каталог `rza_at/`.

## Концепция (ТЗ, разд. 2, 44)

    Нормативные требования → Выпуск 13Б → математическая модель → расчёт режимов (КЗ)
      → расчёт защит → универсальная модель функции РЗА (PFM) → адаптер терминала
      → проверка диапазона/шага → повторная проверка чувствительности и устойчивости
      → карта уставок → отчёт → согласование и утверждение.

Методика Выпуска 13Б — расчётно-методическая **основа** (физические критерии), а не база
параметров конкретного микропроцессорного устройства. Расчётное ядро не знает о Siemens 7UT6:
оно выдаёт параметры «Protection Function Model» (`87T.IdiffPickup`, `51.IPickup`, …), а адаптер
конкретного терминала переводит их в параметры устройства с учётом диапазона и шага, после чего
**обязательно повторяется проверка** критериев. Добавление нового терминала не требует изменения
расчётного ядра — только профиль устройства (конструктор «Добавить устройство»).

## Запуск

```bash
cd rza_at
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
.venv/bin/python run.py 8000        # веб-интерфейс на http://localhost:8000
```

Тесты:

```bash
.venv/bin/python -m pytest tests -q                    # ядро: 27 тестов
NODE_PATH=<node_modules с jsdom> node tools/ui_smoke.js        # смоук-тест интерфейса (сервер должен быть запущен)
NODE_PATH=<node_modules с jsdom> node tools/ui_actions_test.js # интерактивные действия UI
```

## Состав

| Модуль | Содержание |
|---|---|
| `rza/model/` | паспорт АТ/трансформатора (двух-/трёхобмоточные, АТ, однофазные группы), РПН как отдельный объект расчёта, ТТ/ТН, сеть (источники, линии, смежные защиты), библиотека режимов, проект (версии, журнал, защита утверждённого проекта) |
| `rza/calc/` | расчёт КЗ (3ф/2ф/2ф-зем/1ф, max/min, все положения РПН), функции защиты: **87T, 50/51 (с пуском по напряжению), 46, 50N/51N, 21, 49**, проверки чувствительности / устойчивости / селективности, контрольные расчёты по примерам 13Б |
| `rza/normative/` | нормативная база (приоритет источников РК/ПУЭ/ПТЭ/13Б…), версионная библиотека формул (безымянных формул нет), нормативные значения с альтернативами по источникам |
| `rza/terminals/` | реестр терминалов (встроенный каталог + `user_data/terminals/`), профиль устройства (диапазоны, шаги, единицы, соответствие PFM, IEC 61850), адаптеры (эталон — **Siemens SIPROTEC 4 7UT6x V4.6**), импортёр руководств |
| `rza/setpoints.py` | архитектура «расчёт → терминал»: округление, принятые уставки, повторная проверка, статусы 🟢🟡🟠🔴 |
| `rza/trace.py` | трасса «Показать расчёт»: исходные данные → формула (id, версия, источник) → подстановка → результат → принятая уставка → проверка |
| `rza/reports/` | отчёты: расчёт уставок, карта уставок, КЗ, чувствительность, селективность, сравнение терминалов, протокол изменений — PDF/DOCX/XLSX/CSV/JSON; экспорт карты уставок под полным контролем проекта |
| `rza/assistant.py` | инженерный AI-ассистент: объяснение уставки, ошибки и недостатки данных, режим «13Б vs современная РЗА» (без автоматического утверждения уставок) |
| `rza/web/` | JSON API + веб-интерфейс (SPA, русский UI) |

## Веб-интерфейс

Разделы: Обзор и статус · Проект и версии · Журнал изменений · Автотрансформатор · Сеть ·
Режимы · ТТ/ТН · Токи КЗ · 87T · 50/51 · 46 · 50N/51N · 21 · 49 · Проверки · База устройств ·
Назначение · Сравнение терминалов · Карта уставок · Отчёты · Нормативная база · Библиотека
формул · 13Б vs современная РЗА · AI-ассистент · Контрольные тесты · Настройки.

У каждого результата — кнопка **«Показать расчёт»** (формула, подстановка, основание,
принятая уставка, проверка). Без «чёрного ящика»: программа показывает расчётную уставку,
допустимый интервал, шаг терминала, отклонение и повторную проверку.
